# 광역버스 승차난 해소를 위한 탑승가능성 기반 경로 안내 서비스
2026 데이터안심구역 경진대회 출품작


입석 금지로 광역버스 공급은 좌석 수에 고정되어 있고, 좌석은 상류 정류장에서 먼저 채워진다.
교통카드 이용내역으로 버스 한 대씩의 남은 좌석과 실제 도착 간격을 복원하고,
기록에 남지 않는 대기 수요는 SKT 유동인구로 보완해 **정류장·요일·시각별 탑승확률과 기대 대기 시간**을 계산한다.
이를 바탕으로 같은 방향의 더 빨리 탈 수 있는 정류장과 출발 시각을 안내한다.

## 데이터
모두 안심구역 내부 데이터
- 한국교통안전공단: 교통카드 이용내역(수도권), 노선 정보, 노선정류장 정보, 정류장 정보
- SKT: 시간대별·요일별 유동인구 (50m 셀, 서울)
- 분석 기간: 2024년 8월 (한국교통안전공단은 2026 데이터가 있었으나, SKT 데이터와 통일하기 위해 202408 데이터를 사용함)

## 분석 흐름
1. **잔여 좌석·도착 간격**: 차량ID와 승하차 시각으로 운행 회차를 나누고, 정류장 순서대로 재차를 누적해
   버스 한 대씩 정류장 도착 시각과 남은 좌석(41석 - 도착 시 재차)을 복원한다.
2. **정류장 대기 수요 (체류 목적 보정)**: 정류장 전체 노선 승차와 반경 150m 유동인구로
   `정류장 대기 수요 = 유동인구 x 기준 대기 비율 x 정류장 배수 x 요일·시간 배수`를 학습한다 (포아송 회귀).
   좌석 여유가 있던 칸으로만 학습하고, 만석 도착 칸의 대기 수요는 이 식으로 복원한다.
3. **9401 대기 수요 (탑승 노선 보정)**: 정류장·요일·시간대별 9401 점유율을 곱한다.
   다른 정산사업자의 같은 정류장ID 통합, 승차가 적은 칸·만석 도착 칸의 점유율 보정을 포함한다.
4. **줄 서기 재현**: 실제로 온 버스의 순서와 남은 좌석에 1분 단위로 도착하는 대기 수요를 태워
   첫 버스 탑승확률, 기대 대기 시간(중앙값·상위 10%), 만석이라 보낸 버스 수를 계산한다.
   등급: 기대 대기 10분 이하 여유 / 10~20분 보통 / 20분 초과 위험
5. **서비스**: 같은 방향 정류장 중 서울을 빠져나가기까지 가장 빠른 정류장 추천(도보·다른 버스·길 건너 이동 포함),
   지하철역 등 위치 기반 추천, 정류장 변경·출발 시각 조정으로 회피 가능한 탑승 실패 비율



목표: 안심구역 안에서 RunAll.py 한 번 실행 -> export 폴더 생성 -> 반출 신청


------------------------------------------------------------------------------
 2단계. 안심구역 데이터 3개를 data/raw 폴더에 복사
------------------------------------------------------------------------------
안심구역에서 제공하는 원본 파일 3개를 찾아서 "작업 폴더/data/raw/" 안에 복사한다.

   파일 이름                              내용
   seoul_flow_time.csv                   SKT 시간대별 유동인구 (약 404MB)
   seoul_flow_wkdy.csv                   SKT 요일별 유동인구 (약 206MB)
   TB_KOTI_ROAD TRAFFIC INDICATOR.csv    도로공사 차량통행지표

복사 후 data/raw 폴더에는 파일이 6개 있어야 한다 (공개 데이터 3개 + 안심구역 데이터 3개)

!! 파일 이름이 위와 다르면 (예: 대소문자, 띄어쓰기, 확장자)
   -> 이름을 바꾸지 말고 실제 이름을 메모해 둔다. 4단계에서 CONFIG에 적는다.


------------------------------------------------------------------------------
 3단계. 주피터 노트북 열기 + 작업 폴더로 이동
------------------------------------------------------------------------------

4. [셀 1] 지금 위치 확인. 아래를 적고 Shift + Enter

   아니면 아래처럼 작업 폴더 경로로 이동 (경로는 실제 위치로 바꿔 적기)

      %cd C:\작업폴더\dsz-bus-2026

5. [셀 2] 필요한 프로그램이 깔려 있는지 확인

      import pandas, numpy, pyarrow, pyproj, openpyxl, matplotlib

   - "OK" 가 나오면 통과
   - ModuleNotFoundError: No module named 'xxx' 가 나오면 -> xxx 가 없는 것.

6. [셀 3] data/raw 파일 확인

      import os
      os.listdir("data/raw")

   2단계의 파일 6개가 다 보여야 한다


------------------------------------------------------------------------------
 4단계. 설정(CONFIG) 확인하고 고치기
------------------------------------------------------------------------------
--- 4-1. 경부고속도로가 지나는 시군구 이름 확인 ---

[셀 4]
      %run data-engineering/05KecRouteIndex.py --list-only

   !! 도로공사 파일 이름이 "TB_KOTI_ROAD TRAFFIC INDICATOR.csv" 와 다르면 뒤에 실제 이름을 붙인다
      %run data-engineering/05KecRouteIndex.py --list-only --road-indicator-file "실제파일이름.csv"
      (6-1의 --list-emd 를 실행할 때도 똑같이 붙인다)

출력이 두 덩어리로 나온다
  [ROAD_NAME 상위 빈도]                          <- 도로 이름 목록
  [['경부고속도로']가 지나는 SIGUNGU_NAME 상위 빈도] <- 경부고속도로가 지나는 시군구 목록

확인할 것
  (1) 첫 번째 목록에 "경부고속도로" 라는 이름이 정확히 있는가?
      -> 없고 "경부선", "경부고속국도" 처럼 다르게 적혀 있으면 그 이름을 메모
  (2) 두 번째 목록에서 9401이 지나는 시군구를 고른다
      9401 경로: 분당(성남) -> 경부고속도로 -> 서초 -> 한남대교 -> 서울 도심
      -> 성남시 분당구, 성남시 수정구(있으면), 서초구 에 해당하는 이름을 출력에 적힌 그대로 메모
         (예: "성남시분당구" 인지 "성남시 분당구" 인지 띄어쓰기까지 똑같이)

--- 4-2. RunAll.py 열어서 고치기 ---

1. 주피터 파일 목록에서 RunAll.py 
2. 위쪽에 "CONFIG = {" 로 시작하는 부분을 찾는다
3. 아래 항목을 확인/수정한다 (따옴표 " " 와 쉼표 , 는 지우지 말 것)

   "flow_file": "seoul_flow_time.csv",          <- 2단계 SKT 시간대별 파일 이름
   "wkdy_file": "seoul_flow_wkdy.csv",          <- 2단계 SKT 요일별 파일 이름
   "road_file": "TB_KOTI_ROAD TRAFFIC INDICATOR.csv",   <- 2단계 도로공사 파일 이름
   "road_names": ["경부고속도로"],                <- 4-1 (1)에서 확인한 이름
   "sigungu_names": ["성남시분당구", "서초구"],   <- 4-1 (2)에서 고른 이름들
                                                  여러 개면 ["A", "B", "C"] 처럼 쉼표로

4. Ctrl + S 로 저장

--- 4-3. SKT 기준년월 확인 ---

SKT 데이터는 2024년 1~12월이 들어 있다. 우리는 8월(202408)을 쓴다.

[셀 5]
      import pandas as pd
      pd.read_csv("data/raw/seoul_flow_time.csv", sep="|", usecols=["STD_YM"], dtype=str)["STD_YM"].unique()

   - 결과에 '202408' 이 있으면 그대로 둔다
   - 없으면 결과 중 하나를 골라 CONFIG의 "std_ym": "202408" 을 그 값으로 바꾸고 저장


------------------------------------------------------------------------------
 5단계. 실행
------------------------------------------------------------------------------
[셀 6]
      %run RunAll.py

- 셀 왼쪽이 [*] 로 바뀌면 실행 중. 숫자로 바뀌면 끝
- 실행 중에는 노트북을 닫거나 다른 셀을 실행하지 말 것
- 진행 단계가 순서대로 출력된다
      01. 승하차 원본 CSV -> 정류장x시간대
      02. 정류장 좌표
      02b. 정류장 -> 행정동
      03. 정류장x시간대 재차
      03b. 9401 분담률
      05. 도로공사 혼잡 노출 지수
      04 + 06. SKT 유동인구 ...    <- 여기가 제일 오래 걸림
      07. / 09. / 08. / 10.

중간에 나오는 아래 출력은 정상이니 신경 쓰지 않아도 된다
   - 02단계: "좌표 매칭(NODE_ID 기준): 11/57" + 매칭 실패 정류장 46개 목록
             -> 성남 정류장이라 서울 좌표가 없는 게 정상
   - 04 + 06단계: "SKT 유동인구 대상 제외 ... 46개 정류장", "flow_pop 없음 ... 46개 정류장"
             -> 위와 같은 이유. 이후 "정류장 57 -> 11" 로 서울 정류장만 남음

성공하면 마지막 줄에 아래처럼 나온다
      반출 패키지 -> ...\dsz-bus-2026\export (17개 파일)

 6단계. 실행 결과 점검
------------------------------------------------------------------------------
--- 6-1. 경고(⚠) 확인 ---

출력에서 ⚠ 표시를 찾는다. 특히 05단계의 아래 경고

      ⚠ seq34 서울역버스환승센터: '회현동' 도로 없음 -> 중구 전체로 대신

이건 "정류장이 있는 동 이름"과 "도로공사 데이터의 동 이름" 표기가 달라서 생긴 것.
같은 표의 match_level 칸에 "시군구(동 불일치)" 라고 나온 정류장이 대상.
고치는 방법:

[셀 7]
      %run data-engineering/05KecRouteIndex.py --list-emd

   -> 시군구별 동 이름(EMD_NAME) 목록이 나온다
   -> 경고가 난 정류장의 동에 해당하는 이름을 찾는다
      (예: '회현동' 대신 '남대문로5가', '회현동1가' 처럼 법정동 이름일 수 있음.
       서울역 근처면 남대문로5가, 봉래동 등)

RunAll.py CONFIG의 "stop_emd_override" 를 아래 형식으로 채우고 저장
      "stop_emd_override": {34: ["남대문로5가", "봉래동1가"], 35: ["남대문로4가"]},
       ↑ 숫자 = 경고에 나온 seq 번호, [ ] 안 = --list-emd 에 나온 동 이름 그대로

그리고 5단계([셀 6] %run RunAll.py)를 다시 실행

   - 경고 정류장이 많거나 맞는 이름을 못 찾겠으면 그대로 둬도 실행은 된다
     (그 정류장은 시군구 전체 도로로 대신 계산됨. 결과표에 표시가 남음)

------------------------------------------------------------------------------
 문제가 생겼을 때
------------------------------------------------------------------------------
에러는 출력 맨 아래 줄을 보면 된다. 자주 나올 만한 것:

FileNotFoundError: ... 를 찾을 수 없습니다 / No such file
   -> 파일 이름이나 위치가 다름. 2단계 파일 위치와 4-2 CONFIG 파일 이름 확인

필터링된 링크가 0건입니다
   -> 4-1의 도로명/시군구 이름이 데이터 표기와 다름. --list-only 결과와 글자 하나까지 비교

KeyError: 'X_COORD' / 'TMST_00' / 'FLOW_POP_CNT_MON' 같은 영어 이름
   -> 원본 파일의 컬럼 이름이 정의서와 다름. 에러 메시지 전체를 메모해서 나온 뒤 수정

학습 가능한(unconstrained & 유동인구 있는) 칸이 0개
   -> CONFIG의 "tau": 0.6 을 0.8 로 올려서 다시 실행

[반출 차단] ... 원자료 컬럼 포함
   -> 반출 규칙 검사에 걸린 것. 코드 수정이 필요하니 메시지를 메모해서 나온 뒤 수정

MemoryError / 커널이 죽음(Kernel died)
   -> 메모리 부족. 다른 프로그램을 닫고 Kernel -> Restart 후 3단계 [셀 1]부터 다시

계속 [*] 상태로 30분 넘게 멈춰 있음
   -> SKT 파일 읽는 중일 수 있음. 출력이 "04 + 06" 에서 멈춰 있으면 조금 더 기다림

!! 에러 메시지를 메모할 때 원본 데이터 값(유동인구 숫자 등)은 적어 나오지 않는다.
   에러 종류와 파일/컬럼 이름만 적는다.
